# Games

給小朋友學英文字母、單字與注音的小遊戲集合，純前端、不需要安裝，用瀏覽器開啟就能玩，手機和平板也適用。

線上版（GitHub Pages）：<https://gme0313.github.io/games/>

## 遊戲

### ABC 冒險（`abc-adventure/`）

直式畫面的冒險遊戲，使用 [Phaser 3](https://phaser.io/)。可選擇 8 種恐龍當主角（暴龍、三角龍、棘龍、滄龍、腕龍、劍龍、甲龍、翼龍），每次開始會隨機換一組顏色與時段（早晨、白天、傍晚、夜晚）。

- **🦖 冒險之旅**：主角往右走，沿路遇到問號路標就答題，共 10 題，每題最多 3 分。
  - 題型有：看圖選開頭字母、聽英文選圖片、聽英文戳泡泡、大小寫配對（點選或拖曳）。
  - 答對會有小恐龍朋友加入隊伍，連續答對有皇冠和彩虹。
  - 地形會從草原換成海邊、火山或雪地，路上會冒出可以點的小生物。
  - 通關後開寶箱，再看總分。
- **🍎 餵恐龍**：恐龍說出想吃的食物，把對的食物拖到牠嘴巴，每局 8 題。
- **✏️ 描字母**：用手指沿著虛線描英文字母（大小寫）或注音符號，每局 6 個。
- **🔄 換主角**、**🎵 背景音樂開關**（輕柔的水晶鈴音，用程式即時合成）。

題目會用瀏覽器的語音合成念出英文和中文，建議使用 Chrome 或 Edge；英文和中文（台灣）的語音需要裝置有對應的語音包。

### ABC 小遊戲（`abc-game/`）

單一 HTML 檔案的簡單版本，不需要網路也能玩。

- **🎈 戳氣球**：聽到字母後，戳對應的氣球。
- **🍎 字母和圖片**：看圖片選出單字的開頭字母。
- 可選擇字母範圍（A-E、F-J、K-O、P-T、U-Z、全部）。

## 執行

不需要 build，也不需要安裝套件。

- 直接雙擊 `abc-game/index.html` 就能玩。
- `abc-adventure/` 用到 `<script src>` 載入檔案，建議用本機伺服器開啟：

  ```sh
  cd abc-adventure
  python -m http.server 8000
  # 開啟 http://localhost:8000
  ```

  Phaser 從 cdnjs 載入，第一次開啟需要網路。

## 部署

用 GitHub Pages 從 `main` 分支的根目錄發佈，推送到 `main` 就會自動更新。repo 必須維持公開，免費帳號的私人 repo 不能使用 Pages。

## 檔案結構

```
abc-adventure/
  index.html    外殼，載入 Phaser 與下面三個腳本
  js/words.js   題庫（單字、中文、圖示）與出題用的分類
  js/look.js    主角與背景的繪製（全部用程式畫，沒有圖檔）
  js/game.js    語音、音效、各個場景與遊戲邏輯
abc-game/
  index.html    單檔的簡單版（HTML、CSS、JS 都在裡面）
```
